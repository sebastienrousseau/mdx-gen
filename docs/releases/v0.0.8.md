# mdx-gen 0.0.8

## Highlights ⭐️

* **Faster large documents**: code blocks in big documents are highlighted on worker threads before the render, cutting 100 KB to 1 MiB renders by 38-47% in our benchmark, with byte-identical output. `with_parallel_highlighting(false)` opts out.
* **New opt-in features**: `with_lazy_images(true)` adds `loading="lazy"` and `decoding="async"` to Markdown images, the `cache` feature adds `CachingProcessor` for documents rendered again and again, and the `serde` feature loads `MarkdownOptions` from TOML, YAML or JSON config files.
* **Clear scope and international headings**: the docs now say plainly that mdx-gen converts CommonMark and GitHub Flavored Markdown, not MDX (JSX), and a test matrix confirms heading anchors keep Cyrillic, Greek, Arabic, CJK and Thai text.
* **Security floor**: `ammonia 4.2.5` or newer, plus patched `url` and `rustix` in the lockfile.

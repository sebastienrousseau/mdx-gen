# mdx-gen 0.0.6

## Highlights ⭐️

* **No more crash on long runs of email addresses**: with comrak's autolink extension on, about 2,000 bare email addresses in one paragraph used to overflow a 512 KiB thread stack and abort the process. mdx-gen now requires comrak 0.55, which fixes GHSA-xg9p-p4jc-c46g, and a regression test renders 3,000 of them on a 512 KiB thread.
* **Trailing parentheses stay linear**: the same comrak release stops a URL followed by many `)` from taking quadratic time.
* **Tested against current dependencies**: the lockfile moves to ammonia 4.2.1, html-escape 0.2.15, log 0.4.34 and thiserror 2.0.21. The declared requirements are unchanged, so dependents keep the versions their own lockfiles choose.
* **Builds without syntax highlighting**: `cargo test --no-default-features` now compiles and passes, examples, doctests and rustdoc included.

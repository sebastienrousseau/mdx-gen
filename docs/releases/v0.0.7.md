# mdx-gen 0.0.7

## Highlights ⭐️

* **Hardened HTML sanitization (`ammonia 4.2.4`)**: Raises the `ammonia` requirement floor to `4.2.4` to address `RUSTSEC-2026-0373` (case-insensitive CSS `url()` matching), `RUSTSEC-2021-0157` (CSS `url("")` escaping), and `RUSTSEC-2021-0158` (SVG animation element XSS).
* **Unified `comrak 0.56` and `html-escape 0.3` pipeline**: Upgrades `comrak` from `0.55` to `0.56.0` and `html-escape` from `0.2` to `0.3.0`, eliminating duplicate `comrak` versions in downstream `html-generator` and `staticdatagen` builds.
* **Rust 1.89.0 MSRV alignment**: Aligns `rust-version` and `build.rs` minimum compiler version to Rust `1.89.0`.
